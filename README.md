# Time Blocking Planner
A time-blocking based personal productivity dashboard. Plan your day by time slots, track habits, and review how you spend your time across categories.

## Key Features
* **Daily Schedule** — Time-based blocking, 3-stage progress tracking (To Do / In Progress / Done)
* **To-Do List / Today's Tasks** — Global list and date-specific lists, per-item progress tracking
* **Habit Tracker** — Streaks, monthly heatmap
* **Category Stats** — Daily/weekly/monthly time graphs, breakdown by subcategory
* **Learning Progress** — Track progress by pages/lectures, estimated completion date calculation
